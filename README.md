# F16-wepon-mod

add AIM-9X and bullet into GeoFS default F16

Yes this also work in 4.0

# Keybind

"u" -> Toggle on/off

" \ " -> Shoot

"-" / "="  -> Switch wepon

"," / "/" -> Next target

"t" -> Radar toggle

"Shift + u" -> Refill current wepon


# Menu

Menu page can be find in "Option -> General"
